GAME SOLO · PROGRES DI BROWSER INI

Dari desa ke kerajaan.

01 / Kelola pekerja dan sumber dayaKayu dan batu untuk bangunan. Emas untuk merekrut. Daging untuk pelatihan, ekspedisi, dan makanan pasukan. Produksi berjalan otomatis. Gunakan − dan + untuk memindahkan pekerja.
02 / Bangun sebelum berperangBangun barak untuk melatih prajurit. Tingkatkan barak untuk membuka pemanah dan kavaleri. Menara dan tembok menjaga desa saat pasukan menyerang. Satu bangunan dapat dikerjakan setiap saat.
03 / Pilih kekuatan ekspedisiKirim setengah atau semua pasukan dari tab Perang. Kekuatan kiriman harus menyamai pertahanan kamp agar menang. Bekal dibayar dan kekuatan kiriman dikunci saat berangkat. Ekspedisi berlangsung 30 detik. Korban tetap mungkin terjadi.
04 / Bertahan dan menaklukkanMusuh menyerang pertama kali setelah 2½ menit, lalu gelombangnya makin kuat. Perbaiki benteng jika rusak. Kuasai ketiga kamp tanpa kehilangan benteng untuk menang.
05 / Main sesuai waktumuGunakan 1× / 2× untuk kecepatan, P untuk jeda. Game otomatis dijeda saat pindah tab. Progres tersimpan setiap 5 detik dan saat dijeda; produksi tidak berjalan saat halaman ditutup.
